## 🎥 Projeto de Filmes com React

Este projeto foi desenvolvido com **React**, consumindo uma **API de filmes** para exibir informações como pôster, título e descrição.  
Baseado no minicurso do canal **Giovana Moller**:  
📺 [Assista à playlist](https://www.youtube.com/watch?v=b6N29J_utw4&list=PLOzZAH_pgb_QGWVmQwkRFTYhHuG1qKHIR)

### 🚀 Funcionalidades:
- Listagem de filmes a partir de uma API pública
- Exibição de pôster e título dos filmes
- Detalhes individuais ao clicar em um filme
- Navegação entre páginas com React Router

### 🛠️ Tecnologias utilizadas:
- React
- JavaScript
- React Router DOM
- CSS
